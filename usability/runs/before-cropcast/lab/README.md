# before-cropcast: labloop lab

This folder holds a disciplined experiment on this repository's own code.
Run `labloop status` for the paths in use.

1. **Scout** (optional): ask your agent *"Use the labloop-scout skill."* It writes
   `lab/notes/PROPOSALS.md` with ranked, verifiable opportunities.
2. **Frame:** *"Use the labloop-frame skill on proposal N"* (or describe your idea).
3. **Freeze:** you, in your own terminal: `labloop freeze`.
4. **Loop:** *"Use the labloop-experiment skill for 20 experiments."*
5. **Confirm:** *"Use the labloop-finding skill."*

All work happens on this branch. Your main branch is untouched; merge the
improved code back yourself if a finding holds up.
