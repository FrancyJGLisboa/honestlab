# F001: prior work

## How I searched
Uma consulta na web (novembro de 2026): "daily retail ice cream sales forecasting weather temperature regression seasonal naive baseline". Não busquei em bases acadêmicas além disso.

## Closest existing work
- Estudo de 2025 que compara regressão linear e XGBoost para temperatura e vendas de sorvete: https://dspace.aiub.edu/jspui/bitstream/123456789/2663/1/Weathering%20the%20Forecast.pdf . Mesma família de método (regressão com temperatura); não é a mesma configuração (sem erro assimétrico, outros dados).
- Guia de varejo sobre previsão com tempo: https://www.scm.dk/best-practices-weather-based-sales-forecasting . Recomenda partir de uma base com dia da semana e testar o tempo por cima, o que é o que foi feito.

## Assessment
Existem trabalhos parecidos: regressão com temperatura para vendas de sorvete é um método conhecido e nada indica novidade técnica aqui. O achado é local: para esta sorveteria, esse método simples erra bem menos que a média atual e que a reta só com temperatura. Não consegui conferir bases acadêmicas completas nem resultados com os mesmos dados.
